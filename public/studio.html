[05] FAQ

Questions, answered.

Do I need API keys to start?

+
No. Operator Solo runs fully local. Lead scanning, brand generation, logos, and pitch docs all work zero-key. You add Groq/Fal keys only if you want the cloud hybrid Pro tier.

Is this a SaaS or a desktop app?

+
Both. Phase 7 wraps Operator in Tauri for a desktop binary. Phase 8 hardens the web SaaS. Your data lives in your own Supabase project.

Can I white-label for my clients?

+
Yes, on the Studio tier. Strip all TheSaaSsin branding from exports, use your own domain on Cloudflare, bill your clients in your currency via Stripe.

How is this not just another ChatGPT wrapper?

+
Because the value is the cockpit, not the LLM. You get a pre-built lead funnel, brand engine, CRM, and revenue tracker — all wired together. AI is one piece; the workflow is the product.

What AI does it ship with?

+
Groq (Llama 3.3) for sub-second copy, Claude Haiku 4.5 for structured work, Fal.ai + Recraft for visuals on higher tiers. All optional.
